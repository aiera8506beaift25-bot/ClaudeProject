ISSUE #2 - DEPRECATED LAYOUT.TSX VIEWPORT API
================================================================================

SEVERITY:       🟡 MEDIUM
STATUS:         ✅ RESOLVED

DESCRIPTION:
  The root layout (src/app/layout.tsx) was using Next.js 13 API pattern for
  viewport configuration, which is deprecated in Next.js 14.

LOCATION:
  File: src/app/layout.tsx
  Lines affected: 7, 19-20

PROBLEM (BEFORE):
  export const metadata: Metadata = {
    title: '...',
    viewport: 'width=device-width, initial-scale=1',  // ❌ WRONG PLACE
    ...
  }

  export default function RootLayout({children}) {
    return (
      <html>
        <head>
          <meta name="viewport" content="width=device-width, initial-scale=1.0" />
          ...
        </head>
      </html>
    )
  }

ROOT CAUSE:
  Layout.tsx was created using Next.js 13 patterns and not updated for Next.js
  14 API changes when Next.js was upgraded to version 14.2.3.

SOLUTION APPLIED:
  ✅ Imported Viewport type from 'next'
  ✅ Created separate viewport export using Next.js 14 API
  ✅ Removed viewport from metadata export
  ✅ Removed hardcoded viewport meta tag from HTML

FIXED CODE:
  import type { Metadata, Viewport } from 'next'

  export const viewport: Viewport = {
    width: 'device-width',
    initialScale: 1,
  }

  export const metadata: Metadata = {
    title: '...',
    description: '...',
    // viewport removed - handled above
  }

  export default function RootLayout({children}) {
    return (
      <html lang="en">
        <head>
          <meta charSet="UTF-8" />
          {/* meta viewport removed */}
        </head>
        <body>{children}</body>
      </html>
    )
  }

IMPACT:
  - Previous: Deprecation warnings might appear in build
  - After: Proper Next.js 14 API usage, clean build

  ✅ npm run build: ✓ No warnings
